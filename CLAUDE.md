*H5 reader*

Create a python package for reading, extracting 3D datas from a CONVERGE CFD H5 result file. 
The package should be able to: 

- Use VTK modules
- Extract datas from a specific region
- Extract slices from the tumble plane, injector axis. 
- Extract volume datas from a specific geometry or the full domain. 
- Save result in a `.vti` format.

An H5 file is stored in : `./datas/.h5`
